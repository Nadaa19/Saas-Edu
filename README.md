# 🎓 Complete LMS & E-Learning Platform (Laravel 13 & Fortify)

A powerful, modern Learning Management System (LMS) built with **Laravel 13**, **PHP 8.3**, **Fortify**, and **Spatie Permissions**. Features educational hierarchy (Years > Subjects > Teachers > Courses > Lessons), Student & Admin Dashboards, Subscriptions, and PayPal Integration.

---

## 🌟 Key Features
- 🛡️ **Multi-Guard Authentication:** Separate access for Admins, Teachers, and Students.
- 📚 **Educational Hierarchy:** Manage Academic Years, Subjects, Teachers, Courses, and Video Lessons.
- 💰 **Subscription & Plans System:** Set duration-based access plans (Monthly/Yearly) linked with academic years.
- 💳 **PayPal Payment Integration:** Built-in PayPal Checkout flow for courses and subscriptions.
- 🔐 **Roles & Permissions:** Powered by Spatie Laravel-Permission.
- 🎨 **Student Portal:** Browse courses, view lesson details, manage enrolled courses, and update security settings.
